# アプリ制作進捗管理 サイドパネル(Chrome拡張機能)

ダッシュボード(`../dashboard.html`)の**表示専用ビューアー版**です。Chromeのサイドパネル機能を使い、どのタブ・どのウィンドウを開いていても常に横に表示しておけます。

## これは何をする拡張機能か / 何をしない拡張機能か

- **する**: GitHub上の `data/tasks.json` を毎回取得し直して表示するだけ
- **しない**: タスクの追加・完了・コメント送信などの書き込み操作は一切できません(表示専用)

タスクの内容を変更したい場合は、次のいずれかで行ってください。

1. Claude Codeの各ルーム(セッション)に指示する → 実行結果が `data/tasks.json` へコミットされる
2. ダッシュボード本体([Artifact版](https://claude.ai/code/artifact/b395634a-ff68-44cb-a667-92c53448c992))から操作する
3. [実装進捗管理シート](https://docs.google.com/spreadsheets/d/1679CPPuWq4lciwe4BsJTfjJpiZKvKWogETwtauPThYw/edit)を直接編集する

変更が `data/tasks.json` へコミットされた後、このサイドパネルを開き直すか「🔄 最新を取得」を押せば反映されます。**拡張機能自体の再インストール・再読み込みは不要です**(タスクの中身は拡張機種内部に持たず、毎回fetchしているため)。

## インストール方法(デベロッパーモードでの読み込み)

Chromeウェブストアには公開していません(個人利用のため)。以下の手順でローカルに読み込んでください。

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」をクリック
4. この `chrome-extension` フォルダを選択する
5. ツールバーに拡張機能のアイコン(パズルピースの既定アイコン)が表示されるので、クリックするとサイドパネルが開く

## 更新したとき

コードそのもの(`sidepanel.html`のレイアウトやロジック)を変更した場合は、`chrome://extensions` でこの拡張機能の「再読み込み」ボタンを押してください。タスクの中身(文言・ステータス等)だけの変更であれば、その操作は不要です。

## 既知の制約

- タスクIDのコピー機能はクリップボードAPIを使うため、ブラウザによっては初回クリック時に許可を求められる場合があります
- `raw.githubusercontent.com` はCDNキャッシュがあるため、pushしてから反映まで数分ほどラグが出ることがあります
- アイコン画像は同梱していません(既定のパズルピースアイコンで表示されます)
